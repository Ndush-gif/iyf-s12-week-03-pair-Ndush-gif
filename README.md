A shared repository for practicing the team workflow we'll use for CommunityHub: branches, pull requests, code reviews and merge conflicts.

## What's in this repo
- `index.html`: a shared page where each of us adds our own profile card
- `README.md`: this file, used for the merge conflict exercise

## Workflow
1. Create a feature branch for your change
2. Push the branch and open a pull request into `main`
3. Partner reviews, comments and approves
4. Merge once approved
   
3. Your partner reviews, comments and approves
4. Merge once approved
